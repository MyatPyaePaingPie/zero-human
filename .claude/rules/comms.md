# Comms rule
- Before building anything under an issue, comment the decision on the issue. After it lands, comment
  the receipt (commit sha, tests, what is live). No silent work.
- Cross-session messages (SendMessage) are for coordination only; anything with a decision or a
  receipt in it goes on the issue too, or it did not happen.
- Labels: `area:tech` / `area:business` = ownership; `seat:code` / `seat:advisor` = which session acts.
- Never create an issue for something an existing issue covers; comment there and update #18's checklist.
